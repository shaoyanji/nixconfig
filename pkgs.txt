# keep the base layer lightweight and focused on fleet sysadmin & core Unix utilities.
#
# Format (lib/pkg-list.nix, gated by checks.pkg-list): one name per line; `#`
# starts a comment anywhere on the line, so an uncommented entry can keep its
# reason; markdown markers (`-`, `*`, `1.`, `- [x]`) and `## headings` are
# ignored; a dotted path (`python3Packages.requests`) resolves through pkgs.
# To restore a package, uncomment the name — the trailing note stays a comment.
# ==============================================================================
