01 The brief

The cloud outpost of a fleet that provisions every one of its {{devices}} machines from a single Nix flake — and the only member of it that faces the open internet.

{{statusDetail}}

Delphi is not a demo deployment. It is the fleet's outside vantage point: the resolver address every tailnet client is pointed at, a pair of eyes on the home servers from a network that is not the home network, and a shell that stays reachable when the basement does not. What runs here is a module in the same flake that builds the laptops — there is no second way to provision it, no image built by hand, and no state that outlives a rebuild.

02 The machine

An always-free ARM64 instance, chosen for the shape most fleets cannot afford: a public address, 24/7 uptime, and a network position outside every home router.

03 What it runs

The public tier is deliberately small: one TLS virtual host, a health endpoint, and the redirect from port 80. The interesting half is inside the mesh, where a tailnet client gets a proxy per service and a certificate it can verify.

04 The operating envelope

This is a small machine and it is treated as one. Nothing compiles here that a builder can compile elsewhere; binary caches are pulled at line rate and the home link is never in the path.
