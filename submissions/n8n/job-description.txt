Staff Platform Engineer, Agentic Engineering Developer Productivity · AI Coding Agents · Developer Platform Our ambition: an engineering organisation where humans and agents work as one continuously learning system, turning frontier AI capabilities and real-world feedback into more ambitious product development. We want n8n to be the reference for how this is done, without compromising quality, resilience or trust. Your main goal is to make that real. This is a Staff individual contributor role in Developer Platform and the technical driving force behind ACDC (Agent-centric Development Cycle), our engineering-wide initiative for agentic development. Nobody has a playbook for this yet. You'll write ours. You won't start from zero. Agents wired into Linear already automate around 80% of the development cycle on one of our developer platform projects, alongside pilots for insight, feature-flag and PR-review agents and a shared agent harness. Your job is to take this from promising experiments to the way n8n builds software. This role is for someone who thinks about this problem constantly. You run agents all day, rebuild your own workflow every time the frontier moves, and have more ideas than time. You'll stay hands-on, building the first versions yourself, and shape how the work grows beyond one person. What you'll do Set direction and own the outcome Identify where agentic development can make the greatest difference, using developer feedback, existing experiments and engineering performance data. Set the strategy and priorities across agent execution, repository readiness, CI, security and developer workflows. Make build, buy or pass decisions on tools and vendors, and own the cost and value trade-offs, including AI spend. Make decisions where requirements are incomplete and the trade-offs between autonomy, reliability, security and review effort are still emerging. Build alignment through technical proposals, clear decisions and working software, and report progress and impact to engineering leadership. Build the foundations Design and build isolated execution environments where agents can work with the right access to code, tools and context, without exposing secrets or sensitive systems. Own the safety model: which task categories agents may attempt, what they must never touch, and where human review is required, partnering with Security on sensitive areas like auth, billing, permissions and data handling. Make n8n's monorepo agent-ready, working with Architecture and senior engineers on repo structure, testability, boundaries and the context agents need. Integrate agents into how we work Build repeatable workflows that take Linear issues through agent execution, self-verification and review to merged PRs, across a growing range of task types. Integrate agentic workflows with GitHub, CI, test infrastructure and code review, so the agentic path becomes the easiest path for engineers. Extend the loop beyond coding: connect earlier signals like product research and customer requests, and later ones like production metrics, so agents contribute across the whole cycle. Open it up beyond engineering, so PMs, designers and others can turn a well-defined issue into a reviewed, mergeable change. Shape review practices, such as PR evidence that shows what changed, what ran, what risks remain and where human judgment is needed. Measure what works Build benchmarks from real historical engineering tasks to evaluate output quality, failure modes, review burden and production risk. Define and track quality and adoption signals, such as reviewer acceptance rate, CI pass rate, rework rate and developer satisfaction. Use data and feedback to change course, retire what doesn't work, and build trust across engineering. Requirements Must-haves 🔥 Frontier obsession: You live at the frontier.
